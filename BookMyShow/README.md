# 🎬 BookMyShow Database Management System

## 📌 Project Overview

The **BookMyShow Database Management System** is a DBMS mini-project developed using **SQL Server**. It simulates the core functionalities of an online ticket booking platform by managing users, movies, theaters, events, and payment records. The project demonstrates fundamental database concepts such as table creation, data insertion, constraints, and SQL queries.

---

## 🎯 Objectives

* Design a structured and normalized database.
* Manage movie, theater, event, user, and payment information.
* Practice SQL commands such as DDL, DML, and DQL.
* Demonstrate the use of constraints, primary keys, and data types.
* Build a real-world database application using SQL Server.

---

## 🛠️ Technologies Used

* **Database:** Microsoft SQL Server
* **Language:** SQL
* **Version Control:** Git & GitHub

---

## 🗂️ Database Structure

The project consists of the following tables:

### 1. Users

Stores details of registered users.

### 2. Movies

Stores movie information including language, duration, and ratings.

### 3. Theater

Stores theater details such as location and number of screens.

### 4. Event

Stores information about movie shows and other events.

### 5. Payment

Stores payment details for bookings.

## 🚀 How to Run

1. Clone this repository.
2. Open **Microsoft SQL Server Management Studio (SSMS)**.
3. Execute `schema.sql` to create the database and tables.
4. Run `insert_data.sql` to populate the tables with sample data.
5. Execute queries from `queries.sql` to test the database.
